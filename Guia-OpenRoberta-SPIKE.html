Robótica · Windows 10/11 · SPIKE Prime con Pybricks

Open Roberta + SPIKE Prime

Preparación de cada hub (una sola vez) y pasos para programarlo desde el Open Roberta Lab por Bluetooth, sin instalar programas en la PC.

PARTE A

Preparar cada hub

Una sola vez por hub. No requiere usuario administrador.

A1

Revisar los requisitos

  • Navegador Google Chrome o Microsoft Edge. Firefox y Safari no tienen el Bluetooth web que usan Pybricks y Open Roberta.
  • PC con Bluetooth. Muchas PC de escritorio no lo traen: en ese caso hace falta un adaptador Bluetooth USB.
  • Cable USB del SPIKE Prime (solo para instalar el firmware).

No hace falta instalar ningún programa ni driver: todo se hace desde el navegador.

A2

Actualizar el firmware oficial de LEGO (si hace falta)

El instalador de Pybricks necesita que el hub tenga la última versión del firmware oficial. Si hace mucho que no se usa con la app de LEGO SPIKE, conectarlo una vez a la app y dejar que se actualice.

A3

Instalar el firmware Pybricks en el hub

Abrir en Chrome o Edge:

https://code.pybricks.com
  • Tocar el ícono de configuración (engranaje) → Install Pybricks Firmware.
  • Elegir el hub SPIKE Prime y seguir las instrucciones de la pantalla.
  • Conectar el hub por USB y elegir en la ventana del navegador el dispositivo LEGO Technic Large Hub in FS mode.
  • Esperar a que termine: el hub se reinicia solo.
REVERSIBLE

Para volver a usar la app de LEGO SPIKE: en code.pybricks.com → Restore Official LEGO Firmware. Mientras tenga Pybricks, el hub no funciona con la app oficial.

A4

No emparejar el hub en Windows

La conexión Bluetooth la hace siempre el navegador. En Windows solo hay que tener el Bluetooth activado, pero el hub no se agrega desde la configuración.

Revisar en Configuración → Bluetooth y dispositivos: si aparece el hub (por ejemplo Mouse (SPIKE Prime) o con otro nombre), entrar y tocar Quitar. Si Windows lo tiene emparejado, el navegador no puede usarlo.

A5

Probar el hub en Pybricks

En code.pybricks.com: crear un archivo nuevo (ícono de hoja o +) y elegir Python. Pybricks crea una plantilla con las líneas import y hub = PrimeHub(). Agregar Icon en la línea de pybricks.parameters y las líneas del programa debajo de hub = PrimeHub(). El archivo completo queda así:

from pybricks.hubs import PrimeHub
from pybricks.pupdevices import Motor, ColorSensor, UltrasonicSensor, ForceSensor
from pybricks.parameters import Button, Color, Direction, Port, Side, Stop, Icon
from pybricks.robotics import DriveBase
from pybricks.tools import wait

hub = PrimeHub()

hub.speaker.beep(500, 300)       # pitido de 500 Hz durante 300 ms
hub.display.icon(Icon.HEART)     # corazón en la matriz de luces
wait(2000)                       # espera 2 segundos
hub.display.text("Hola")         # "Hola" desplazándose en la matriz
print("Listo!")                  # mensaje en la consola de la PC

Encender el hub, tocar el botón de Bluetooth de Pybricks, elegir el hub y luego ▶. Debe pitar, mostrar el corazón y después "Hola". El texto de print aparece en la consola de la PC, no en el hub.

IMPORTANTE

Al terminar la prueba, desconectar el hub con el botón de Bluetooth y cerrar la pestaña de Pybricks. El hub acepta una sola conexión a la vez.

PARTE B

Programar el hub en clase

Cada vez que se usa el SPIKE Prime.

B1

Preparar la PC y el hub

  • Activar el Bluetooth de Windows.
  • Cerrar cualquier pestaña de code.pybricks.com.
  • Encender el hub con el botón central.
B2

Entrar al Lab y elegir el sistema

https://lab.open-roberta.org

Elegir la tarjeta Spike Prime / Robot Inventor / Pybricks, dejar Neural networks sin marcar y tocar get started.

B3

Armar el programa de prueba

Debajo del bloque start, enganchar el bloque show image ♥ LED matrix (categoría Acción) y luego un wait ms (categoría Control):

start
  show image ♥ LED matrix
  wait ms 3000

El wait es necesario: cuando el programa termina, el hub borra la matriz de luces y la imagen desaparece al instante.

B4

Ejecutar y emparejar

Tocar ▶ (abajo a la derecha). El navegador abre la ventana "lab.open-roberta.org quiere emparejarse": elegir el hub de la lista y tocar Emparejar.

El corazón aparece en la matriz de luces durante 3 segundos.

B5

Saber qué es normal

NORMAL

En robot ▾ → info el nombre aparece como "-" y el voltaje vacío. A diferencia del EV3, el SPIKE no queda vinculado: el navegador se conecta cada vez que se toca ▶.

Para ejecutar el programa sin la PC: el hub guarda el último programa enviado. Apagar el Bluetooth de la PC (o cerrar el Lab) y apretar el botón central del hub.

⚠ SI ALGO FALLA

La ventana del navegador dice "Activar Bluetooth para permitir el emparejamiento"

  • El Bluetooth de Windows está apagado: tocar Activar Bluetooth en esa ventana o activarlo en Configuración → Bluetooth y dispositivos.

"Looks like you didn't select a device"

  • Se cerró la ventana sin elegir el hub. Verificar que el hub esté encendido, tocar ▶ otra vez y, si no aparece, Volver a detectar.

"Looks like your robot is already connected to another instance…"

  • El hub está tomado por otra pestaña (Pybricks u otro Lab) o por Windows. Cerrar las otras pestañas, quitar el hub de Windows (A4) y apagar y encender el hub.

El hub no aparece en la lista del navegador

  • Probablemente no tiene Pybricks instalado (con el firmware de LEGO no aparece): repetir A3. También verificar que la PC tenga Bluetooth.

La imagen o el texto no se ven en el hub

  • Agregar un wait ms al final del programa (B3).

En los bloques de Pybricks aparece un triángulo de aviso

  • Falta declarar el hub: en Setup, poner el bloque Prime Hub dentro de set up y elegirlo en el desplegable del bloque. En Python lo hace la línea hub = PrimeHub().
